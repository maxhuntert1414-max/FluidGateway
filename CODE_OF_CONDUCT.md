# Code of Conduct

## Our Standard

FluidGateway contributors should be respectful, technically honest, and open to
evidence that challenges an assumption. Productive disagreement is welcome;
harassment, discrimination, threats, doxxing, and personal attacks are not.

Examples of positive participation include:

- giving specific, actionable review feedback;
- separating measurements from hypotheses;
- crediting prior work and contributors;
- documenting regressions and failed experiments;
- helping new contributors reproduce results.

## Scope

This standard applies in repository issues, pull requests, discussions, and
other project spaces.

## Enforcement

Report unacceptable behavior privately to the repository owner through GitHub.
Maintainers may edit or remove content, reject contributions, or temporarily or
permanently restrict participation when behavior harms the project community.
